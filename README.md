## Data Structure Projects

This repository contains the projects I made for the Data Structure course I took in my 3rd year at university. This course covered many important topics such as linked lists, stacks, queues, trees, and graphs. I completed four projects in this course, and I describe them below:

# Project 1: Polynomial Equation Solver

In this project, I implemented a system to solve polynomial equations using stacks and linked lists. The program reads the polynomial terms, stores them in a linked list, and uses stack operations to simplify and calculate the result.

# Project 2: Football Tournament Real Runner-Up

This project uses stacks and queues to determine the winner and the real runner-up of a football tournament. The system simulates matches in rounds, finds the champion, and then calculates the best team among all teams that lost to the champion to get the real runner-up.

# Project 3: AVL Tree and BFS Search with Hash Function

The third project involves building an AVL tree and performing a BFS (Breadth-First Search) on it. I also implemented a hash function to efficiently manage and search data within the tree.

# Project 4: Graphs and Network Routing

In this project, I used graphs to model networks and determine network routes. The program finds the shortest paths and possible routes between nodes, helping to simulate network routing in a simple way.
